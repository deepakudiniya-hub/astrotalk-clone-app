## Payment Flow (Razorpay)

```
User "Add Money" click kare
        |
        v
Amount enter kare (jaise ₹200)
        |
        v
Razorpay checkout khule
(UPI / Card / Net banking)
        |
        v
Payment success
        |
        v
Firestore mein transaction record add ho
        |
        v
User ka walletBalance update ho (+₹200)
        |
        v
Wallet screen pe balance dikhe (₹200)
```

### Razorpay Fees:
- UPI: 0% (free)
- Credit/Debit card: 2%
- Net banking: 2%
- Wallet: 2%

**Example:** User ₹100 add kare card se -> Razorpay ₹2 lega -> ₹98 wallet mein jayega
UPI se ₹100 add kare -> ₹0 fee -> ₹100 wallet mein jayega
